# 네뷸라 · 니케 (nikke.nebula.kim)

구글 스프레드시트 **"[승리의 여신 : 니케] 육성 시트"**를 불러와서 캐릭터 카드로 보여주는 사이트입니다.
시트가 수정되면 몇 분 안에 사이트에도 자동으로 반영됩니다.
Nebula 사이트 모음([nebula.kim](https://nebula.kim))의 하나로, 맨 위 전환 바·테마·알림창은 허브 저장소(`Nebula-sw/nebula-hub`)의 공용 스크립트를 씁니다.

- 화면: HTML 한 장 (`public/index.html`, 빌드 과정 없음)
- 서버: Cloudflare Worker 한 파일 (`src/worker.js`) — 시트를 읽어 JSON으로 바꾸고, 시트 이미지를 대신 받아 전달
- 비용: Cloudflare 무료 플랜

## 기능

- 캐릭터 카드: 초상화, 이름, **속성**, 기업, 무기, 스킬 빌드업 4단계, 오버로드 우선순위, 유효 추가 옵션, 큐브, 소장품·애장품, 메모
- 필터: **속성**(작열·수냉·풍압·전격·철갑) / 기업 / 무기 / 사용처(PVE·PVP) / 애장품, 그리고 검색
- **카드 색 = 속성 색** (작열 빨강 · 수냉 파랑 · 풍압 초록 · 전격 보라 · 철갑 노랑). 기업은 색으로 나누지 않음
- 라이트 / 다크 / 시스템 모드 (맨 위 바의 [테마] 버튼). 포인트 색은 빨강 고정
- 초상화를 못 받아오면 자동으로 몇 번 다시 시도
- 마지막으로 받은 데이터를 브라우저에 저장해 두고, 다음에 열면 먼저 바로 보여준 뒤 새 데이터로 바꿈
- 홈 화면에 추가하면 앱처럼 열림, 카톡 공유 썸네일

## 파일 구성

| 파일 | 역할 |
|---|---|
| `public/index.html` | 화면 전체 (스타일·필터·카드 그리기) |
| `src/worker.js` | `/api/data`: 시트 → JSON (5분마다 뒤에서 새로 만들고, 그동안은 저장본을 바로 돌려줌) / `/api/img`: 시트 이미지 중계 (구글이 다른 사이트에서 바로 띄우는 걸 막아서, 브라우저에 1년 캐시) |
| `wrangler.jsonc` | Cloudflare 설정 |
| `public/favicon.svg`, `apple-touch-icon.png`, `icon-*.png`, `og.png`, `manifest.webmanifest` | 아이콘·썸네일·홈 화면 설정 (원본은 nebula-hub/docs/og) |

## 시트 읽는 방식 (src/worker.js)

- 시트 내용: 구글 시트의 공개 JSON 주소(`gviz`)로 읽음. 열 위치는 파일 위쪽 `COL` 표
- 초상화: 시트의 HTML 보기(`htmlview`)에서 각 행의 이미지 주소를 찾아 이름과 짝지음
- 다른 시트를 쓰려면 파일 맨 위 `SHEET_ID`, `GID`만 바꾸면 됨

### 속성은 어떻게 알아내나
시트에는 속성이 글자로 없고, 초상화 오른쪽 아래에 **떠 있는 아이콘 그림**으로만 붙어 있습니다. 그 그림은 직접 받아볼 수 없어서(구글이 막음) 그림 내용은 보지 않고 이렇게 정합니다 (`parseElements`).

1. 시트 HTML에 적힌 그림 위치(몇 번째 행·열, 칸 안 x좌표)로 초상화 오른쪽에 붙은 그림만 골라 그 행의 니케와 짝지음 (왼쪽 위 그림은 버스트 아이콘이라 제외)
2. 같은 속성 아이콘은 그림 주소가 같으므로, 주소가 같은 것끼리 묶으면 5묶음
3. 속성을 확실히 아는 **기준 니케**(`ELEMENT_ANCHORS`: 모더니아=작열, 헬름=수냉, 노아=풍압, 엑시아=전격, 레드후드=철갑)가 들어 있는 묶음에 그 속성 이름을 붙임

시트 주인이 아이콘을 새로 올려도 기준 니케만 시트에 있으면 자동으로 다시 맞춰집니다. 기준 니케가 시트에서 빠지면 그 속성은 빈 값이 되니 `ELEMENT_ANCHORS`에서 다른 니케로 바꿔 주세요.

## 로컬 실행 / 배포

```bash
npx wrangler dev        # http://localhost:8787
```

- 배포: `main`에 push하면 Cloudflare가 자동 배포 (Deploy command `npx wrangler deploy`), 도메인 `nikke.nebula.kim`
